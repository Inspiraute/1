한자결 v2 · 아이폰용 웹앱 배포 파일

중요: 이 ZIP은 iPhone에 직접 설치하는 앱이 아니라 웹사이트를 만드는 소스 묶음입니다.
파일 앱에서 HTML을 미리보기만 하면 JavaScript가 차단되어 버튼이 눌리지 않을 수 있습니다.

웹사이트 배포 (GitHub Pages 예시):
1. GitHub에서 새 공개 저장소(repository)를 만드세요.
2. 이 ZIP의 압축을 풀어 내부 파일 5개(index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png)를 저장소 최상위에 업로드하세요.
3. Settings -> Pages -> Build and deployment -> Deploy from a branch -> main / (root)를 선택해 저장하세요.
4. 발급된 https 웹사이트 주소를 아이폰 Safari로 여세요.
5. Safari 공유 메뉴 -> 홈 화면에 추가를 누르면 앱 아이콘으로 사용할 수 있습니다.

주의: 데이터는 Safari의 해당 웹사이트에 저장되며 기기 간 자동 동기화는 지원하지 않습니다. 정기적으로 JSON 백업을 보관하세요.
